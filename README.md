# Aplicaciones Reales - Sistemas Embebidos

Repositorio correspondiente al ejercicio desarrollado en clase sobre aplicaciones reales de sistemas embebidos.

## Contenido

### Punto 1 - MicroPython en Wokwi

Desarrollo y simulación de un sistema basado en ESP32 utilizando MicroPython.  
El montaje utiliza dos pulsadores y dos LEDs y permite trabajar con eventos, tareas y comunicación entre procesos.

### Punto 2 - Introducción a YOLO

Revisión del funcionamiento de la arquitectura YOLO y desarrollo de una prueba utilizando Python, Ultralytics y OpenCV para realizar detección de objetos mediante una cámara.

### Punto 3 - Integración YOLO + ESP32

Integración de detección de objetos con el sistema embebido.

El sistema deberá:

- Detectar un carro de juguete y encender el LED rojo.
- Detectar una moto de juguete y encender el LED verde.

## Herramientas utilizadas

- ESP32
- MicroPython
- Wokwi
- Python
- OpenCV
- Ultralytics YOLO
- Visual Studio Code
